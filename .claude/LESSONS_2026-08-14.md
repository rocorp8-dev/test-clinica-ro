## Lecciones Clave

### 1. Parser iCal Sin Dependencias Externas

**Problema:** `node-ical` causó error de build (`s.BigInt is not a function`).

**Solución:** Parser manual implementado directamente:

```typescript
function parseIcsText(icsText: string): ParsedIcalEvent[] {
  const events: ParsedIcalEvent[] = []
  const lines = icsText.replace(/\r\n /g, '').split(/\r?\n/)

  let currentEvent: Partial<ParsedIcalEvent> | null = null

  for (const line of lines) {
    if (line === 'BEGIN:VEVENT') {
      currentEvent = { isAllDay: false }
    } else if (line === 'END:VEVENT' && currentEvent) {
      events.push(currentEvent as ParsedIcalEvent)
      currentEvent = null
    } else if (currentEvent) {
      // Parsear UID, SUMMARY, DTSTART, DTEND, DESCRIPTION
    }
  }
  return events
}
```

**Lección:** Cuando una librería causa problemas de compatibilidad con Next.js/Turbopack, implementar parser manual simple es mejor que debuggear dependencias.

### 2. Fail-Safe Pattern para Integraciones Externas

**Implementación:**

```typescript
// API Route - SIEMPRE retorna 200 con success: true
export async function GET() {
  try {
    // ... lógica
  } catch (error) {
    return NextResponse.json({
      success: true,  // ← Nunca false
      events: [],     // ← Array vacío, no error
      message: 'Error interno, agenda nativa funcionando normalmente'
    })
  }
}

// Frontend - Carga en paralelo, no bloquea
const loadGoogleCalendarEvents = useCallback(async () => {
  try {
    const response = await fetch('/api/calendar/google-ical')
    const data = await response.json()
    if (data.success && Array.isArray(data.events)) {
      setGoogleCalendarEvents(data.events)
    }
  } catch {
    setGoogleCalendarEvents([])  // ← Silencioso
  }
}, [])
```

**Por qué funciona:**
- Si Google falla → usuario no ve error, app sigue funcionando
- Si URL no configurada → array vacío, sin mensajes molestos
- Citas nativas NUNCA se afectan por estado de Google

### 3. Cambios 100% Aditivos en Producción

**Checklist aplicado:**
- Columna nullable (no rompe datos existentes)

**Lección:** En sistemas con usuarios activos, SIEMPRE hacer cambios aditivos, nunca destructivos.

### 4. Visual Distintivo para Fuentes Externas

**Implementación:**
- Citas nativas → Estilo emerald (verde)
- Citas Google → Estilo blue (azul) con badge "Google"
- Separador visual cuando hay ambos tipos

**Por qué funciona:**
- Usuario identifica inmediatamente el origen
- No hay confusión entre citas "reales" y sincronizadas
- Acciones diferentes para cada tipo (Google = solo lectura)
