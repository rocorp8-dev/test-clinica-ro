## 📚 Lecciones Clave

### 1. Cambios de Copy = Bajo Riesgo

**Contexto:** Usuario pidió eliminar una leyenda.

**Approach:**
- ✅ Identificar exactamente qué eliminar con Grep
- ✅ Eliminar el div completo (no dejar elementos huérfanos)
- ✅ Commit inmediato y push

**Lección:** Cambios de texto/copy son los más seguros. No requieren verificación exhaustiva.

---

### 2. Pricing Dinámico = Calcular en Runtime

**Estructura de datos existente:**
```typescript
plans = [
  { name: "Básico", monthly: 449, annual: 359 },
  { name: "Pro+", monthly: 849, annual: 679 },
  { name: "Clínica", monthly: 2100, annual: 1680 }
]
```

**Cálculo simple:**
- Total anual normal = `plan.monthly * 12`
- Total anual con descuento = `plan.annual * 12`

**Lección:** No hardcodear totales. Calcular desde datos existentes para mantener consistencia.

---

### 3. Color como Indicador de Valor

**Implementación visual:**
- Precio normal → `text-slate-500` (gris neutro)
- Precio con descuento → `text-emerald-400` (verde = ahorro)

**Por qué funciona:**
- ✅ Usuario asocia verde con beneficio/ahorro
- ✅ Contraste visual inmediato
- ✅ No requiere texto adicional

**Lección:** Usar color para comunicar valor sin añadir palabras.
